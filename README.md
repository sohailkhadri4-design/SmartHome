# Smart Home Automation

A smart home automation project focused on monitoring and controlling home devices through an embedded/IoT system.

## Project Overview

This repository is being used to organize the firmware, hardware notes, and documentation for the Smart Home project.

The main goal is to build a practical system that can:

- Monitor connected home devices or sensors
- Control electrical loads through a microcontroller-based system
- Provide a simple interface for device control
- Keep the hardware and software structure easy to test and extend

## Hardware

The exact controller, sensors, communication method, and switching hardware should match the hardware used in the project. They will be documented here as the implementation is added.

## Software

The software is organized around:

- Sensor and input handling
- Device control
- Communication
- Application logic
- Basic fault and functional testing

## Development Notes

I am keeping the repository structured so that hardware-specific code, documentation, and tests can be maintained separately.

Exact pin assignments, device models, communication settings, and control logic will be documented alongside the implementation rather than guessed in the README.
